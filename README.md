- `src/` — source code
- `tests/` — tests
- `scripts/` — utility scripts
- `assets/` — static/design assets
- `docs/` — documentation
  - `docs/design/` — design artifacts
  - `docs/architecture/` — architecture docs
  - `docs/roadmap/` — planning and milestones
